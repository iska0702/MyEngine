# Графика и очистка мира — 16 октября 2026

## Изменения мира

Стартовый мир: Floor (плоская земля), House Walls и House Roof (две части одного дома). Удалены демонстрационные цветные источники света, порталы и подземный мир. Исходники PortalSystem, WorldDimensionSystem и PortalVisuals удалены; удалены обработчики клавиш, вызовы обновления/отрисовки, интерфейс и ссылки из Windows/macOS/PS4/CMake сборок.

Обновлены scene_save.txt, main.level и создание main.level по умолчанию. Сохранения старого демонстрационного мира однократно переводятся на чистую стартовую сцену. Новые сохраняются с WORLD_LAYOUT 3, чтобы последующие добавления в редакторе не исчезали. SaveManager сохраняет предыдущий Save1.save в .bak при замене.

## Исправления графики

- **Несовпадение DXR с видимыми объектами.** XMStoreFloat3x4 уже транспонирует матрицу DirectXMath в формат DXR. Дополнительное XMMatrixTranspose теряло перенос и искажало вращение. Исправлено для статических и динамических экземпляров. DxrTransformRegression сравнивает преобразованные точки с обычным рендером для единичной матрицы, переноса и комбинированного неравномерного масштаба/вращения/переноса.
- **Плавающие тени.** Привязка проекции карты теней к texel grid теперь использует фиксированную точку мира. Прежний якорь двигался вместе с камерой и всегда оказывался около нуля в координатах света.
- **Фильтрация теней.** В PCF используется comparison sampler: сравнение глубины выполняется до интерполяции результатов. Прежний вариант интерполировал саму глубину. Нулевая глубина больше не трактуется как пустая карта: карта очищается значением 1.
- **Нормали при масштабе.** Исправлено преобразование нормалей в растровом и DXR шейдерах при неравномерном масштабе.
- **HDR и чёрные поверхности.** Убрано обрезание DXR яркости до диапазона 0–1 до тонмаппинга (включая RayGen и path tracing). Композитор определяет попадание по alpha, а не по ненулевому RGB: чёрные поверхности не заменяются растровой картинкой.
- **Сброс GPU при отключении DXR.** DRED показал зависание compute-прохода. Astra GI продолжал использовать TLAS после отключения DXR и замены сцены. Проход теперь требует включённый DXR и актуальную структуру сцены. Пустые нормали поверхностного кеша не отправляются в RayQuery; исправлено расположение констант освещения и защита накопления GI от NaN.
- **Слишком тёмная сцена.** Исправлен завышенный коэффициент поглощения солнечного света облаками. Ясная погода использует плотность 0,2 вместо 0,8. Убраны скрытый демонстрационный объём Dark Crypt и принудительная кинематографическая обработка; по умолчанию используется нейтральная цветокоррекция.
- **Экранное освещение.** SSAO и SSGI используют FOV и диапазон глубины основного рендера. SSGI больше не декодирует уже знаковые нормали G-buffer как текстуру 0–1.
- **Локальные источники света.** Исправлено выравнивание массивов point/spot lights по регистрам constant buffer. Тест проверяет смещения 576 и 1088, размеры элементов 32 и 64 байта. Соответствующая упаковка uniform-структур Metal приведена к CPU-формату.
- **Время жизни ресурсов.** Синхронизация GPU выполняется перед обновлением общих upload-буферов и перед освобождением SDK-ресурсов. При потере устройства benchmark завершает работу с кодом 3 и пишет DRED-диагностику вместо бесконечного цикла.

Родное разрешение используется по умолчанию. DLSS/FSR/XeSS остаются доступными как отдельные режимы, но их полная визуальная проверка в эту проверку Windows native rendering не входит.

Для визуальной проверки benchmark сохраняет последний кадр из swapchain в benchmark_frame.bmp и список объектов в benchmark_world.txt рядом с exe. Захват выполняется после измерения кадров и не входит в время рендера CSV.

## SDK и Steamworks

Пути сборки и упаковки обновлены под ThirdParty: Streamline 2.14.1, XeSS SDK 3.0.2, Discord SDK, DirectX-Headers, FidelityFX SDK 1.1.4 и исходники PhysX 5.12. PhysX собран с динамическим CRT; новые PhysX.dll/PhysXCommon.dll/PhysXFoundation.dll используются вместе с соответствующими заголовками и import libraries. Старые DLL PhysX удаляются из пакета.

Отсутствовавшие SDK WebView2 1.0.4258.31 и DirectStorage 1.3.0 восстановлены из официальных NuGet-пакетов в ThirdParty. Для Deflate используется локальная копия miniz 1.15 с сохранённой лицензией в заголовке, без зависимости от расположения Assimp. Добавлен tools/Build/BuildPhysX.ps1; build.bat запускает его автоматически, если PhysX.lib ещё не собран.

Steamworks временно отключён по умолчанию в build.bat и CMake. Команды: `build.bat release standalone` и `build.bat editor standalone`. В этом режиме нет определения ENGINE_PLATFORM_STEAM, линковки/delay-load Steam API, вызова инициализации или автозапуска Steam. Старые Steam DLL удаляются из output. Исходники интеграции сохранены для последующего включения; для этого понадобятся SDK и явное MYENGINE_ENABLE_STEAM=1 (либо одноимённая CMake option).

## Облака и появление растительности — 17 октября 2026

Дополнительная проверка по замечанию пользователя обнаружила геометрию вне списка Models: TerrainSystem автоматически создавал процедурный рельеф и 3500 экземпляров растительности. Его Render был внутри if (rain.enabled), поэтому они появлялись только с дождём. TerrainConfig.enabled теперь false по умолчанию для чистого мира; при явном включении через редактор terrain рисуется независимо от дождя. Предыдущая проверка списка трёх Models не охватывала этот отдельный проход.

Облака неба и облачные тени использовали разные масштаб шума, движение по Z, высоту и штормовое покрытие. Эффективный коэффициент поглощения тени был 0,005, а видимых облаков — 0,015. Добавлен общий shaders/cloud_common.hlsl для raster, DXR и cloud resolve: единая плотность, границы слоя, ветер и Beer–Lambert extinction 0,015. Луч к солнцу интегрируется по восьми точкам. Тени следуют плотности облаков; при плотности 0 пропускается весь солнечный свет.

Для воспроизводимой проверки добавлены параметры benchmark --benchmark-rain и --benchmark-clouds <0..3>. Они действуют только в benchmark, который не сохраняет сцену при завершении.

Проверка дождя дополнительно обнаружила автоматически созданный демонстрационный костёр в ParticleSystem::Initialize. Автосоздание удалено; явно созданные пользователем частицы теперь выводятся независимо от дождя. Таким образом, чистый мир не получает скрытые демонстрационные объекты из TerrainSystem или ParticleSystem.

Проверка обновления 17 октября: обе финальные standalone-сборки через build.bat завершились успешно; startup-check обеих вернул 0. Скомпилированы PS raster, PS cloud resolve и DXR library с общей моделью облаков. Сравнение Release при cloud density 0 и 0,8 показало затенение геометрии: пиксель земли (640,600) изменился с RGB (196,199,205) на (53,68,90), а не только изменилось небо. Эти кадры: ReleaseBuild/clouds_off.bmp и clouds_on.bmp.

После удаления демонстрационного костра повторены 45 кадров дождя в Release с DXR и 45 кадров в Editor без DXR; оба запуска завершились с кодом 0. Финальные кадры rain_clean.bmp и rain_clean_raster.bmp проверены визуально: земля и дом остаются, дополнительного рельефа, растительности и костра нет. renderer_error.log и gpu_validation.log отсутствуют в обоих каталогах. Снимок Release также сохранён как rain_clean.png.

## Высота персонажа и наложение теней — 17 октября 2026

Тень здания внутри облачной тени допустима: облако частично ослабляет прямой солнечный свет, здание перекрывает оставшийся прямой свет. В shader lighting используется произведение пропускания облака и видимости солнца; цвет не умножается повторно от кадра к кадру. Рассеянное освещение остаётся отдельным вкладом, поэтому полная чёрная заливка не требуется.

Найден конфликт двух систем движения: после CharacterController::Update камера получала позицию глаз PhysX, а затем Camera::Update ещё раз интегрировал собственную вертикальную скорость и гравитацию. Это опускало камеру относительно капсулы; следующий CCT update возвращал её выше. Теперь при включённом CCT камера принимает его позу и grounded state, а собственная гравитация/ограничение плоскостью работают только в запасном режиме без CCT. После инициализации капсула выставляется в положение игрока с учётом уровня Floor и её размеров.

При приседании setHeight заменён на PhysX resize, сохраняющий положение стоп. Позиция глаз рассчитывается из текущей высоты капсулы, без дополнительного повторного масштабирования смещения.

Добавлен CharacterCameraRegression на реальном PhysX: 600 кадров покоя с чередованием 30 и 144 Гц, точное следование камеры капсуле, приседание без перемещения стоп, выдержка в приседе, вставание, прыжок, приземление и сохранение запасной гравитации камеры. Диапазон высоты в покое: 0 м. Полный набор CTest: 7/7 успешно.

Обе сборки с исправлением персонажа полностью пересобраны через build.bat release/editor standalone. Финальные startup-check вернули 0. Контрольный прогон Release на 45 кадров и Editor на 30 кадров завершился успешно; ошибок потери GPU не зарегистрировано.

## Коллизия дома и видимая граница дождя — 17 октября 2026

Включённый флаг COLLISION раньше использовался запасной камерой и дождём, но сам по себе не создавал PhysX actor при PHYSICS_BODY 0. Стартовые стены и крыша теперь имеют static physics body; старые сохранения с включённой коллизией дома получают статическое тело при загрузке. Коллайдер стен соответствует объёму 6 × 3,5 × 7 м с локальным центром на высоте 1,75 м. Крыша — выпуклая пирамида по реальным вершинам меша: основание Y=3,45, вершина Y=5,7, свесы X=±3,4 и Z=±3,9. Габариты запасной коллизии и дождевого укрытия также приведены к размерам дома с учётом масштаба/поворота.

Область симуляции дождя остаётся возле камеры ради ограничения числа частиц. У капель и брызг теперь радиальная плавная прозрачность в наружных 35% радиуса: квадратные края и углы не обрываются резко. Сами брызги сохраняют мировые координаты; отдельная плоскость земли с объёмом дождя не перемещается.

Дополнительно диагностический шейдер shadowFactor выявил тёмный прямоугольник растровых теней: у shadow texture отсутствовал SampleDesc.Count=1, поэтому создание depth resource могло завершаться неудачно. Пустой SRV возвращал нулевую глубину, затеняя всю область проекции, следующую за камерой. Исправлено описание ресурса; Pad2 теперь передаёт доступность настоящей карты теней, и при её отсутствии шейдер не сравнивает глубину с пустым SRV.

Расширен CharacterCameraRegression: движение персонажа в стену дома, проверка отсутствия завышенного объёма коллайдера, raycast по наклонному скату крыши и плавная видимость на границе/в углах дождевого объёма.

Финальная проверка этого изменения: обе полные standalone-сборки через build.bat завершились успешно; startup-check Release и Editor вернули 0. Все 7 CTest-проверок прошли. Release прошёл 30 кадров native raster без облаков, Editor — 45 кадров native raster с дождём, оба с кодом 0. Визуально проверены house_raster.bmp и house_rain_raster.bmp: прежний тёмный прямоугольник отсутствует, тень дома корректно ограничена геометрией; дождь не добавляет рельеф или отдельную землю. renderer_error.log и gpu_validation.log отсутствуют в обеих сборках. Растровый кадр без дождя также доступен в ReleaseBuild/house_raster.png.
