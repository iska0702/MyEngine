# Сеть и античит

## TLS 1.3 в Windows

Защищённый режим использует Microsoft MsQuic 2.6.1 (OpenSSL): QUIC поверх UDP с TLS 1.3. Проверяются цепочка доверия, срок сертификата и имя сервера. При ошибке соединение завершается: перехода на открытый UDP нет. Ранние данные 0-RTT не используются. Серверный PFX загружается в память без установки закрытого ключа в системное хранилище.

Серверу нужен собственный сертификат с закрытым ключом в PFX и DNS-именем сервера в SAN. Держите его вне Content и дистрибутива игры. Пример запуска в PowerShell (переменная окружения заранее содержит пароль):

```powershell
./ServerBuild/IdontknowServer.exe --port 7777 --tls-pfx D:/Private/server.pfx --tls-password-env IDK_TLS_PFX_PASSWORD
```

Альтернатива в `server.cfg`:

```ini
tls_enabled=true
tls_pfx=D:/Private/server.pfx
tls_password_env=IDK_TLS_PFX_PASSWORD
```

Пароль не передаётся в командной строке и не печатается в журнал. Разрешите входящий UDP на выбранный порт. Серверная конфигурация по умолчанию сохраняет прежний UDP: для защищённого сервера явно включите TLS и задайте PFX.

В Multiplayer редактора TLS включён по умолчанию. Подключайтесь по DNS-имени из сертификата. В Advanced можно отдельно задать имя сертификата (например, при подключении по IP) и PEM-файл доверенного частного CA. Этот CA применяется только к соединению; системное хранилище не изменяется. Без PEM используется стандартная проверка доверия провайдера. Отключать проверку сертификатов нельзя. Флажок legacy UDP явно включает незашифрованный режим и нужен для старых серверов.

Для программного клиента задайте `TlsOptions` через `NetworkClient::SetTlsOptions`: `enabled`, `serverName`, при необходимости `caCertificate`. Для сервера используйте `ServerConfig::tls`. Низкоуровневые API сохраняют прежний UDP по умолчанию; `MultiplayerManager` включает TLS по умолчанию. На Linux/macOS TLS пока не реализован: запрос защищённого режима возвращает ошибку, обычный UDP остаётся доступен.

Все игровые пакеты сейчас передаются через один ограниченный надёжный двунаправленный QUIC-поток. При потере пакетов следующие сообщения этого потока ожидают восстановления; это отличается от независимых ненадёжных UDP-снимков. Независимые QUIC DATAGRAM-каналы здесь пока не реализованы.

## Усиление античита

- Повторы и устаревшие пакеты отклоняются до обработки ACK и обновления времени активности.
- Ограничены очередь надёжных пакетов, число повторных отправок, входящие очереди TLS, объём исходящих данных и число ожидающих соединений; неавторизованные игровые сессии истекают.
- Добавлен бюджет новых игровых подключений по IP. Превышение не создаёт бессрочную блокировку IP.
- Challenge nonce генерируется системным криптографическим генератором; при ошибке нет предсказуемого запасного генератора.
- Имя отправителя чата берётся из серверной сессии; управляющие символы очищаются, частота сообщений ограничена.
- Существующие серверные проверки перемещения, стрельбы, очередности и сроков integrity-ответов покрыты регрессиями. MsQuic DLL включена в проверку runtime-модулей и упаковочный манифест.

TLS защищает передачу и удостоверяет сервер. Он не удостоверяет учётную запись игрока и не доказывает отсутствие читов на его компьютере. Клиентская integrity-телеметрия остаётся недоверенным сигналом; это не аппаратная удалённая аттестация и не драйверный античит.

## Сборка и проверки

`build.bat` автоматически вызывает `tools/Dependencies/FetchMsQuic.ps1`. Официальный пакет `Microsoft.Native.Quic.MsQuic.OpenSSL` версии 2.6.1 закреплён SHA-256 `E8BFDD6A4D4E561FD5213EAB3C617D231D2F2E5E926E3D3DE682FFA540938B08`. Runtime размещается в `ThirdParty/Microsoft/MsQuic/msquic.dll` рядом с редактором, игрой и Windows-сервером.

```powershell
./tools/Diagnostics/CheckNetworkSecurity.ps1
./tests/ServerLifecycle.ps1 -Executable D:/MyEngine/ServerBuild/IdontknowServer.exe
./tests/ServerTlsLifecycle.ps1 -Executable D:/MyEngine/ServerBuild/IdontknowServer.exe
```

Первый скрипт требует PowerShell 7 и создаёт временные тестовые сертификаты в Diagnostics/TlsFixtures без изменения системного доверия. Тесты проверяют игровой обмен через TLS 1.3, отсутствие открытого текста сообщений в UDP-перехвате, повторы/повреждение шифротекста, внедрение открытого UDP, закрытие сессий, неверное имя, недоверенный CA, просроченный сертификат и отсутствие перехода на открытый транспорт. Тестовые ключи не упаковываются в игру. Журналы: Diagnostics/NetworkRegression.log и Diagnostics/TlsRegression.log.

Во всех трёх сборках присутствует MsQuic с действительной подписью Microsoft; тестовых PFX/PEM/KEY в каталогах сборок нет.
