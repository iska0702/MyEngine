# Проверка ReleaseBuild и мыши — 16 октября 2026

## Запуск

До пересборки ReleaseBuild/MyEngine.exe был старым (21 сентября), тогда как EditorBuild уже обновлялся. Точную причину отказа старого бинарника воспроизвести не удалось; считать её установленной нельзя.

Оба варианта успешно пересобраны через `build.bat release steam` и `build.bat editor steam`. Новый Release прошёл проверки целостности и два реальных прогона по 180 кадров с кодом выхода 0. Защита при обычном запуске сохранена. Добавлены `--startup-check`, файл startup_check.txt и журнал security.log рядом с exe для диагностики отказов.

## Исправление мыши

InputMapping::Update забирал и обнулял сдвиг мыши, после чего камера повторно читала уже пустой ввод. Теперь платформа опрашивается один раз, а камера использует сохранённый сдвиг текущего кадра. Чувствительность и инверсия Y применяются к этому сдвигу без умножения на время кадра.

На Windows захваченная мышь использует WM_INPUT, накапливая относительные аппаратные перемещения. Старый способ с перемещением курсора в центр оставлен как запасной при отказе регистрации Raw Input. Учтены потеря фокуса и переключение захвата.

MouseInputRegression проверяет однократное чтение, сохранение полного сдвига при повторном доступе и очистку на следующем кадре при 15, 60 и 240 FPS. Тест прошёл. Физическое ощущение мыши требует ручной проверки.

## Производительность

RTX 3060, Release, 180 кадров, первые 30 исключены. Последний кадр обоих прогонов: внутренний размер 742×418. Динамическое разрешение и нагрузка системы могут менять результаты; это сравнение одного запуска каждого режима, не стабильная оценка производительности всех сцен.

| Среднее | DXR включён | DXR выключен |
|---|---:|---:|
| Время кадра | 55,99 мс (~17,9 FPS) | 12,64 мс (~79,1 FPS) |
| Update | 11,47 мс | 4,53 мс |
| Render на CPU, включая ожидания | 44,21 мс | 8,06 мс |
| Ожидание GPU fence | 17,95 мс | 4,38 мс |
| GPU timestamp | 12,19 мс | 4,76 мс |

Замеры: ReleaseBuild/benchmark_rt.csv и benchmark_no_rt.csv. Существенная часть задержки связана с DXR и его подготовкой на CPU, а не только с GPU. Отключение VSync в предыдущей паре прогонов устойчивого улучшения не дало. Графические настройки пользователя автоматически не изменялись.

Для повторения: `MyEngine.exe --benchmark 180` и `MyEngine.exe --benchmark 180 --benchmark-no-raytracing`. CSV сохраняется рядом с exe; тест завершается автоматически без сохранения сцены. GPU timestamp readback исправлен на READBACK heap. Счётчик FPS использует реальное время вместо ограниченного шага физики.
